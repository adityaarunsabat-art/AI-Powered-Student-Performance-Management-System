# Student Performance Dashboard

## Overview

A web-based dashboard for analyzing and monitoring student academic performance. The system provides interactive visualizations, student rankings, subject-wise analysis, and performance insights.

## Features

* Student Performance Analysis
* Subject-wise Marks Visualization
* Student Rankings
* Pass/Fail Analysis
* Interactive Charts and Graphs
* Performance Dashboard

## Tech Stack

* Python
* Streamlit
* Pandas
* Plotly

## Dataset

The dashboard uses a CSV dataset containing student marks in multiple subjects.

## Installation

1. Clone the repository
2. Install dependencies

pip install -r requirements.txt

3. Run the application

streamlit run app.py
